# Project Euler — C++ Solutions

A collection of solutions to [Project Euler](https://projecteuler.net/) problems, implemented in **C++20**.

Project Euler offers mathematical and computational challenges that test logical reasoning and algorithmic thinking.

## Purpose

This project is part of my development as a computer science student. Its goal is to strengthen my mathematical foundations, improve my problem-solving skills, and deepen my understanding of efficient algorithm design through C++.

## Language

- **C++20**

## Structure

Each problem has its own directory containing the implementation and corresponding documentation.
